# 🚀 Projeto Impulsojob — CAMPL & VR Software

Este repositório é dedicado ao **Projeto Final de Currículo** desenvolvido por **Leonardo Donizete**, estudante do **CAMPL**, no programa **Impulsojob** promovido em parceria com a **VR Software**.

---

## 📌 Sobre o Projeto

O **Impulsojob** foi concebido com o propósito de atuar como um **portfólio prático e teste de currículo automatizado**. Trata-se de uma aplicação estruturada em **Java** desenvolvida durante a formação técnica.

A aplicação representa a versão inicial funcional (MVP/base de testes), pronta para demonstrar a bagagem adquirida no curso e servir como alicerce para futuras melhorias, refatorações, otimizações e expansões de código.

---

## 🛠️ Tecnologias & Ferramentas

* **Linguagem:** Java  
* **IDE / Ambiente:** NetBeans  
* **Automação de Build:** Gradle  
* **Controle de Versão:** Git & GitHub
